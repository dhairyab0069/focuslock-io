Playable simulator

A little Mac, a real watchdog, your rules.

Everything below is a simulation running in your browser. It never looks at your computer, tabs or programs: the Mac is pretend. Press ? for keyboard shortcuts.

Right-click the desktop for a menu. Drag title bars; flick a window and it glides. Drag a notification onto Notes to park it.

LLMs pause your timer

If a desktop LLM app or the Claude Code command line is running, the screen goes red and the countdown stops. No credit for cheated minutes. Close it and the session resumes by itself.

Browsers are filtered, not blocked

Search, documentation, YouTube and music all work, because concentration fuel is allowed on purpose. Social media and LLM websites get redirected away and counted.

It can never trap you

A pre-flight check, a 30 second grace button, an SOS button on every overlay, a keyboard shortcut and a terminal command. Ending early is one click.

A note on the name: the “LLM watchdog” is a watchdog against LLMs. It is ordinary code that looks at what is running; it is not itself a language model, and the app does not send anything anywhere.

Browser filtering

A blocklist, not an allowlist.

Blocking the whole web would make focus harder, not easier: you need search and documentation. So the filter only names the places that eat an hour.

  1. It reads the front tab’s address from Safari, Chrome, Brave, Edge or Arc, but only while that browser is the frontmost app. That is the one permission it asks for (Automation).
  2. It checks the host against the list. A match is the domain itself or any subdomain of it. Blank tabs, browser pages and local files are never filtered.
  3. If it matches, the tab is sent to a blank page, the miss is counted, and a short message says why. If it cannot read the tab (permission missing) the browser stays locked and says so.

        The other half: the LLM watchdog

        Outside the browser, the watchdog looks for LLM programs in two ways, because one is not enough: it asks macOS which desktop apps are running (Claude, ChatGPT, Perplexity, Copilot, Gemini), and it reads the full command lines of running processes to catch command line tools. Claude Code, for example, renames its process to its version number, so a plain name search misses it. A scan runs every 5 seconds; the browser check runs every 2.

        Emergency killswitches

        A lock you can always open.

        A commitment device that traps you gets uninstalled. So there are several ways out, each ends everything at once, and you can try every one of them in the simulator above.

        Pre-flight check

        It refuses to start while an LLM is open, and lists exactly what to close, instead of dropping you onto a red screen. Tick “Claude (app)” in the simulator and press Lock in.

        Grace button

        The red screen offers “Give me 30 seconds to close it.” The clock stays paused but the screen stands down so you can reach the program.

        SOS button

        On every overlay, the emergency exit ends the session now. One click, no questions.

        Keyboard

        ⌘⇧Esc

        Works while an overlay is up. In the simulator, Ctrl+Shift+Esc works too.

        Terminal

        focuslock unlock (or stop) from any terminal ends everything. focuslock status says whether it is running.

        Ending early

        One click on a confirmation that tells you how many minutes are left. No typing rituals. Quitting with ⌘Q during a session opens the same question instead of quitting.

        Honest limits: this is a commitment device, not a prison. focuslock unlock beats it, and your phone exists. Its job is to make drifting loud and immediate instead of silent, which is usually all a wandering brain needs to snap back.

        Design

        Low stimulation, on purpose.

        A focus tool that shouts is its own distraction. The app and this page follow the same few ideas.

        One job

        A timer and a blocker. No streaks, no scores, no feeds. The only counter is how many distractions were turned away.

        Loud only when it matters

        Quiet screens most of the time; a full-screen message only when you actually drift. Then it explains itself in one plain sentence.

        No friction to leave

        Anything that needs willpower to escape gets abandoned. Every exit is one step.

        Allow the fuel

        Music and reference material help people concentrate, so they are not policed.

        Yours to quiet

        On this page: large type, soft colours, no autoplay. Stop all motion and Sound are in the top bar; motion starts off if your system asks for reduced motion, and sound is always off until you switch it on. Both choices are remembered on this device only.

        Nothing leaves this page

        No trackers, no web fonts, no external requests. The simulator is code on this page, not a monitor.

        Using it

        What it needs.

        A Mac

        macOS 14 or later. It is a small native app written in Swift and SwiftUI.

        One permission

        Automation, so it can read the front browser tab. Allow it in System Settings, Privacy and Security, Automation. Without it the browser stays locked during sessions and everything else still works.

        No account, no key

        There is nothing to sign in to and nothing to configure for the watchdog: it does not call an LLM, an API or any server.
